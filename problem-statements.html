Hackathon Problem Statements

Explore the three challenge domains for Qiskit Fall Fest 2026. Build innovative solutions using quantum computing and quantum machine learning.

DOMAIN 01

Hybrid Quantum–Classical Breast Lesion Classification

Healthcare · Quantum ML

Develop a hybrid quantum–classical machine learning model using compressed ConvNeXt features and a Variational Quantum Circuit (VQC) to classify breast lesions into Benign, Atypical, and Malignant categories using the BRACS dataset. Compare its performance with a classical model having a comparable number of trainable parameters.

Goal: Evaluate classification performance against a comparable classical model.
DOMAIN 02

Quantum Kernel Learning for Cancer Prediction

Healthcare · Quantum Kernels

Build a quantum kernel-based machine learning model to predict clinical outcomes, such as survival risk, EGFR/KRAS mutation status using the TCGA-LUAD dataset, or axillary lymph node metastasis using the BCNB dataset. Compare its performance with classical SVM and XGBoost models.

Goal: Compare quantum kernel learning with classical prediction models.
DOMAIN 03

Quantum Machine Learning for Indian Agricultural Productivity

Agriculture · Quantum Regression

Develop a Variational Quantum Regression model to forecast crop yield in India using features such as rainfall, fertilizer usage, and cultivated area. Compare prediction accuracy, model complexity, and computational efficiency with Random Forest and XGBoost.

Goal: Evaluate quantum regression against established crop-yield prediction models.
